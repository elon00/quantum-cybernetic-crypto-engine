## 🔑 Core Features & Cryptographic Primitives

- **Real secp256k1 Elliptic Curve Keys:** Genuine public/private key pairs compatible with Bitcoin and Ethereum standards (`crypto.generateKeyPairSync('ec', { namedCurve: 'secp256k1' })`).
- **Cryptographic Signatures:** Every transaction requires a genuine SHA-256 ECDSA digital signature verified against the sender's public key before entry into the mempool.
- **SHA-256 Proof-of-Work:** Blocks are mined by discovering target nonces satisfying dynamically adjusted difficulty targets.
- **Merkle Tree Verification:** Cryptographic root calculations for block payload integrity.
- **Live Real-Time Price Oracle:** Automated background fetching from live exchanges for BTC, ETH, and SOL.
- **Zero Third-Party Dependencies:** Built entirely on Node.js standard libraries (`crypto`, `http`, `fs`, `path`). Never breaks on missing npm packages.
